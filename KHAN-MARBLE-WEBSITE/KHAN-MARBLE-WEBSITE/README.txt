KHAN MARBLE & TILE STORE WEBSITE
================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted KHAN-MARBLE-WEBSITE folder in VS Code.
3. Open index.html in your browser by double-clicking it.
4. No VS Code extension or local development server is required.

PROJECT STRUCTURE
- index.html              Homepage
- pages/about.html        About Us
- pages/marble.html       Marble collection
- pages/tiles.html        Tiles collection
- pages/services.html     Services
- pages/gallery.html      Gallery with lightbox
- pages/faqs.html         FAQ accordion
- pages/contact.html      Contact form that prepares a WhatsApp message
- css/style.css           Shared responsive styling
- js/script.js            Navigation, FAQ, gallery and contact form interactions
- images/                 Add your own local photos here

DEPLOYMENT
